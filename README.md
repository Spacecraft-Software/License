## Project Posture

Spacecraft Software is a **personal hobby project**. Most subprojects — including this
one — are developed at hobby pace and shaped around the maintainer's own use
case, not a general audience. Selected subprojects (e.g., **Anvil-SSH**) are
intentionally designed for general use and say so explicitly in their own
README.
